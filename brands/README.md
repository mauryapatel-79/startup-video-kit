# brands/

Brand memory: one folder per brand, captured once and reused by every video. Your brands are git-ignored; only the kit's own brand is committed as an example.

```bash
node scripts/brand.mjs init https://your-startup.com   # first time
node scripts/brand.mjs check your-startup              # before each video
node scripts/brand.mjs list
```

Format and rules: [skills/startup-video/references/brand.md](../skills/startup-video/references/brand.md).
