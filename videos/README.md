# videos/

One folder per video, each a HyperFrames project. Your folders are git-ignored so client work never lands in a public fork; only `example-launch/` is committed.

```
videos/<slug>/
  BRIEF.md        what the video is for
  SCRIPT.md       scenes, timing, narration (approved before building)
  CREDITS.md      licences for music, SFX, fonts, footage
  index.html      root composition
  compositions/   one file per scene
  assets/         voice, screens, logo, sfx, music
  renders/        delivered files
```
